FORJA GYM 2.0.0 — COMO ATUALIZAR O CÓDIGO E GERAR APK
=====================================================

1) Extraia FORJA-Gym-2.0.0-Android-Kotlin.zip.
2) Abra a pasta extraída ForjaGym.
3) Copie TODOS os arquivos e subpastas internos para a pasta local do projeto Git
   que você já enviou para: https://github.com/Renaton0/Aplicativo-Gym
   Substitua os existentes; não apague .git.
   Inclua .github/workflows/gerar-apk.yml (já corrigido).
4) Abra o terminal na pasta local do repositório e rode:

   git add -A
   git commit -m "FORJA Gym 2.0.0"
   git push origin main

5) Acesse https://github.com/Renaton0/Aplicativo-Gym/actions
6) Abra a execução "Gerar APK Android" do último commit.
7) Quando ficar VERDE, clique em "ForjaGym-APK-instalavel" (Artifacts).
8) Baixe e extraia o ZIP do GitHub. Instale app-debug.apk no Android.

ATENÇÃO: APKs debug gerados em execuções diferentes do GitHub podem ter
assinaturas diferentes. O Android pode recusar instalar 2.0 por cima de 1.0.
Não desinstale 1.0 se precisar preservar os dados ainda não copiados.
Desinstalar apaga normalmente os dados locais do aplicativo.

Os dados principais funcionam offline; as fotografias do Commons exigem
internet na primeira visualização. O aplicativo também permite usar fotos
locais pessoais de equipamentos.

O APK 2.0 ainda precisa passar pela compilação real do GitHub Actions.
